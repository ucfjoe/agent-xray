# Session dependency evidence

Approved scope: connect the session map for JavaScript, TypeScript, Python, Go and Kotlin. Import relationships are static evidence, never runtime call claims.

1. Analyze bounded recorded source evidence with a known lexical starting point. Never read current files to explain historical snapshots; never combine unrelated excerpts.
2. Resolve only unambiguous recorded targets. Preserve unresolved imports and coverage diagnostics. Go needs recorded module metadata; Kotlin uses declared packages, not folder guesses.
3. Derive analysis when reading current or retained history, after evidence recovery. Do not rewrite history or change attribution.
4. Project file edges onto visible groups. Show coverage before the graph and distinguish unavailable evidence from no observed imports.
5. Test all languages, false positives, ambiguity, historical isolation, grouped edges and real adapter-to-render fixtures. Render narrow/medium/wide screenshots in the cloud; require expert review before sign-off.

Limit: this is partial static analysis of recorded evidence, not a build-system or runtime dependency graph. Missing source prefixes and unresolved build aliases must remain visible limitations. Demo graph success is not session integration verification.
